# Social deduction games (Werewolf/Mafia, Avalon/Resistance, Among Us, Secret Hitler, Spyfall, Chameleon) as sandboxes for populations of LLM agents — literature review as of October 2026

Scope note: all numbers below were read from the primary PDFs/HTML (downloaded 2026-10-05) unless marked "(unverified)". Where a paper does not report a quantity (e.g. tokens per game) that is stated explicitly rather than guessed.

## Key Question 0 — Scorecard: each game against the five criteria (API/buildability, long-run cost, published LLM/MARL baselines, rigorous metric, interpretability)

### Takeaway
Werewolf is by far the most mature sandbox on criteria 1, 3 and 4 (multiple open engines, ≥10 training papers incl. RL/self-play/population methods, and a Google DeepMind ~31,500-game game-theoretic rating protocol that explicitly corrects for role luck), but it is the most expensive per game (8–9 players, 12–13 min and ~$0.3–1 per game with API models). Among Us (text version) is the cheapest for *training* (a 1.5B model trained on one A40 in <48h) and has the only Elo-with-bootstrap-CI deception metric, but published baselines are thinner. Avalon has strong self-improvement work (Strategist, ICLR 2025) with strategy-as-text, but tiny evaluation samples (10–60 games). Secret Hitler, Spyfall and Chameleon each have one serious 2025–26 benchmark and are 4–5-player (cheap) but have no training/population literature.

### Cited Findings
- Werewolf — engines: Google's Werewolf Arena (Apache-2.0, includes an interactive web viewer; repo archived read-only on Sept 24 2025, 48 stars) — [GitHub google/werewolf_arena](https://github.com/google/werewolf_arena); Google DeepMind Game Arena harness (Apache 2.0, "full game trajectories to support reproducible benchmarking") — [Game Arena paper](https://arxiv.org/abs/2609.31473), [repo](https://github.com/google-deepmind/game_arena); WereWolf-Plus (12- and 8-player with Sheriff, code open-sourced at MinstrelsyXia/WereWolfPlus) — [arXiv 2506.12841](https://arxiv.org/abs/2506.12841); Xu et al. 2023 original 7-player code — [github xuyuzhuang11/Werewolf](https://github.com/xuyuzhuang11/Werewolf); also Werewolves in TextArena (74 games, TrueSkill ladder) — [TextArena](https://arxiv.org/abs/2504.11442) and in Social Gym (21 games) — [Social Gym](https://arxiv.org/abs/2608.09128).
- Werewolf — rigorous metric: Game Arena evaluates ~31,500 8-player games with "game-theoretic evaluation (GTE)" that "decomposes each model's overall skill into role-specific contributions (Werewolf, Seer, Doctor, Villager)" because "raw win rates conflate individual skill with role-assignment luck", with bootstrap CIs — [Game Arena](https://arxiv.org/abs/2609.31473).
- Werewolf — cost: WOLF reports "Each full Werewolf game required approximately 12–13 minutes when using LLM calls" and "Running 100 games with logging produced about 6GB of NDJSON data and required roughly 21 GPU-hours" on one A100 40GB — [WOLF](https://arxiv.org/abs/2512.09187); MafiaScope (7-player Mafia) reports "At July 2026 prices a probed gpt-4o-mini game costs a median $0.36 and 36 minutes; a probed DeepSeek game about $0.26, an unprobed one $0.01" — [MafiaScope](https://arxiv.org/abs/2607.10645).
- Among Us — engine + metric: open sandbox (CC0) with Deception Elo / Detection Elo and 90% bootstrap CIs; 2,054 seven-player games cost "$2000 of OpenRouter API credits" (≈$0.97/game across 18 models); 400 Llama-3.3-70b/Phi-4 games cost "$100 in total" (≈$0.25/game) — [Among Us sandbox, NeurIPS 2025 spotlight](https://arxiv.org/abs/2504.04072), [repo 7vik/AmongUs](https://github.com/7vik/AmongUs).
- Among Us — MARL training exists at small scale: 1.5B RWKV crewmates trained with RL + listening/speaking losses; "All experiments were conducted on individual A40 GPUs with 48 GB of VRAM. All models can be trained within 48 hours of compute" — [Sarkar et al. AAMAS 2025](https://arxiv.org/abs/2502.06060).
- Avalon — engine + baselines: AvalonBench (5-player, rule-based bots, ReAct agents; 164 stars; Strategist code in `strategist/`) — [AvalonBench](https://arxiv.org/abs/2310.05036), [repo jonathanmli/Avalon-LLM](https://github.com/jonathanmli/Avalon-LLM); Strategist self-improvement via "population based self-play, where we conduct round-robin games among the top ten strategies" reaches human parity (human win 0.367±0.089 vs Strategist 0.333±0.061, 30 games) — [Strategist ICLR 2025](https://arxiv.org/abs/2408.10635).
- Secret Hitler — ParliamentBench: "16 LLMs across more than 1,600 five-player Secret Hitler matches (100 games per model)" vs a reference dataset of "25,000 online games played by human players"; "Gameplay resulted in 100 million total completion tokens" — [ParliamentBench](https://arxiv.org/abs/2607.28146). Open framework with replay-from-JSON — [Bauer 2026](https://arxiv.org/abs/2605.22826), [repo](https://github.com/itsniklas/secret-hitler-player).
- Spyfall — Multicultural Spyfall: 5-player, 6 models, "a total of 9,000 matches", 600 matches per model, Bradley–Terry ratings, run on openrouter.ai — [arXiv 2601.09017](https://arxiv.org/abs/2601.09017).
- Chameleon — Karabag et al.: 4-player, 100 games per configuration; non-chameleon LLM teams win 0–11% vs a trivial concealing strategy's ~23%; code released — [arXiv 2501.19398](https://arxiv.org/abs/2501.19398), [repo](https://github.com/mustafakarabag/LLMChameleon); Chameleon environment also exists in Farama ChatArena — [ChatArena](https://github.com/Farama-Foundation/chatarena).

### Inferences
- For "thousands of games per generation", Werewolf at 8–9 players is roughly 2–3× the per-game cost of a 4–5-player game (Chameleon/Spyfall/Avalon/Secret Hitler) and ~1.3× Among Us (7 players), simply from player count × rounds; the WOLF/MafiaScope numbers (12–36 min per game) mean a serial Werewolf run of 1,000 games is ~200–600 machine-hours unless games are parallelised.
- Only Werewolf (Game Arena GTE) and Among Us (Deception Elo + bootstrap CIs) have a published, not-game-specific rating protocol that addresses role luck; Secret Hitler (ParliamentBench) and Spyfall use Bradley–Terry/Elo but on a single fixed opponent or small model pool.

### Gaps
- No paper reports a single matched table of tokens/dollars/minutes per game across games; the per-game costs above come from different player counts, models and years and are not directly comparable.

## Key Question 1 — Main LLM-agent papers and environments per game (code, model sizes, games run, headline results)

### Takeaway
Werewolf has the deepest stack: prompt-only (Xu 2023, Werewolf Arena), RL-over-LLM (Xu ICML 2024, Thinker 2024, ONUW NeurIPS 2024), preference/latent-policy fine-tuning (MaKTO NeurIPS 2025, LSPO ICML 2025, Stackelberg Speaker ICLR 2026), and large-scale evaluation (Game Arena 2026, ~31.5k games). Avalon has AvalonBench, ReCon and Strategist. Among Us has AmongAgents, the FAR AI sandbox (2,054 games, 18 models) and the Stanford MARL paper. Secret Hitler/Spyfall/Chameleon have one benchmark each (2025–26) and no training work.

### Inferences
- Werewolf is the only game where an open-weight ≤8B model has been trained to beat prompt-only frontier baselines in published work (LSPO on Llama-3-8B; Stackelberg Speaker refiner on Qwen2.5-7B; MaKTO on Qwen2.5-14b/72b), which matters if the startup wants cheap local populations.
- Among Us is the only game with a published end-to-end MARL result on a sub-2B model (Sarkar), i.e. the lowest known per-agent inference cost for a learning population.

### Gaps
- MaKTO's code/model release could not be located in the PDF (no GitHub URL in the text); treat as "not open" unless the OpenReview page says otherwise.
- Xu et al. ICML 2024 appears to have no code release (project website only); the WebFetch summary said "Not available" and the PDF lists only the site.
- WOLF's PDF text never names the LLMs that played the 100 games (model identity could not be extracted).

## Key Question 2 — How papers evaluate skill: games per estimate, variance, reference pools, Elo/TrueSkill

### Takeaway
Most training papers use 100 games per matchup (Xu 2024, MaKTO, LSPO) and report ±0.05–0.11 standard errors; evaluation-only papers range from 10 games/pair (Werewolf Arena, admittedly non-robust) to ~31,500 games (Game Arena). The best protocols for a population sandbox are Game Arena's GTE (per-model, per-role parameters, bootstrap CIs, handles non-transitivity), Among Us's Deception/Detection Elo with 1,000-sample bootstrap CIs, MaKTO's TrueSkill over random seatings, and ParliamentBench's fixed-opponent 100-game design (which cannot resolve <14 pp).

### Cited Findings
- Game Arena: "every model pair is evaluated under identical conditions in a full round-robin, with outcomes logged … per-game for Werewolf"; GTE from Liu, Gemp, Marris, Piliouras, Heess & Lanctot, "Re-evaluating open-ended evaluation of large language models", ICLR 2025 ([26] in the paper); "Confidence intervals are computed via bootstrap"; the paper compared GTE with "Elo [27] and OpenSkill [28, 29]" and argues traditional ratings "often conflate an individual model's core skill with the structural base win rates of their randomly assigned roles" — [Game Arena](https://arxiv.org/abs/2609.31473). The Kaggle page describes the metric as an "equilibrium win rate", computed with the polarix library, with models required to have played "a minimum number of games (e.g., at least three)" to be listed — [Kaggle Werewolf leaderboard](https://www.kaggle.com/benchmarks/kaggle/werewolf) (page is JS-rendered; details taken from search summary — partially unverified).
- Game Arena rule-balance study: 500 self-play games per rule configuration with Gemini 3 Pro controlling all 8 seats; Villager win rate 0.734±0.039 (standard) → 0.567±0.043 (balanced ruleset) — i.e. 95% CI half-width ≈4 pp at n=500 — [Game Arena](https://arxiv.org/abs/2609.31473).
- Among Us: "we compute 90% confidence intervals through bootstrap resampling with replacement for 1000 iterations"; Elo with K=32, base 1500, impostor expected score E = 1/(1+10^((Rc−Ri)/400)) against the average crewmate rating; "The variance in bootstrap samples can be partly explained by the variability of game outcomes based on random initialization and the stochasticity of LLMs" — [Among Us sandbox](https://arxiv.org/abs/2504.04072).
- MaKTO: 100 head-to-head games (50 per faction); "Random competitions with diverse role assignments across 260 games, MaKTO-72b achieved the highest TrueSkill rating"; human-mixed 30 games → 61.8%±8.3% — [MaKTO](https://arxiv.org/abs/2501.14225).
- Xu ICML 2024: 100 games per cell of a 5×5 cross-play matrix; values with SEs such as "0.30 (0.03)" and "0.36 (0.05)"; human group 2: 140 participants in 20 teams × 30 consecutive games — [arXiv 2310.18940](https://arxiv.org/abs/2310.18940).
- LSPO: 100 games per evaluation; overall win 0.50±0.11; ablation Village side 0.18±0.09 — [LSPO](https://arxiv.org/abs/2502.04686).
- Stackelberg Speaker: "500 matches per game with randomly sampled agents" — [arXiv 2510.09087](https://arxiv.org/abs/2510.09087).
- ParliamentBench: "At n = 100 per model (and only n = 20 per deceptive role), the paired design cannot reliably resolve overall win-rate differences below roughly 14 percentage points"; so they "report the win-rate ordering as a top cluster rather than a strict ranking"; an anchor-opponent tournament of 450 games showed win rate is opponent-unstable (mean Kendall τ −0.33 across swapped opponents) while their fine-grained metrics are stable (RIA +0.55, DRR +0.33, GSIR +0.11) — [ParliamentBench](https://arxiv.org/abs/2607.28146).
- Werewolf Arena: 10 games per pairing; "may not provide statistically robust results" — [arXiv 2407.13943](https://arxiv.org/abs/2407.13943).
- Spyfall: Bradley–Terry "following Chatbot Arena's metric"; 600 matches per model; "Each game is played once" per configuration — [arXiv 2601.09017](https://arxiv.org/abs/2601.09017).
- Social Gym: Elo "BT-MLE, anchored mean 1000; 95% bootstrap CIs"; rosters "enumerating all model combinations per game and running a fixed number of episodes per combination, with role and seat assignments balanced"; team games count only cross-team pairs; separate Elo-Alt (deceptive minority) and Elo-Main — [Social Gym](https://arxiv.org/abs/2608.09128).
- MindGames: TrueSkill with (μ=25, σ=25/3); Stage II "minimum-play requirements (50 games in Secret Mafia, 30 games for each Generalization environment)"; "we report cumulative reward alongside TrueSkill … especially in environments where invalid actions and forfeits can distort leaderboard meaning" — [MindGames](https://arxiv.org/abs/2605.29512).
- Auditing paper: paired design with shared random seeds (7000–7199), 200 games per arm, McNemar test; explicitly: "final win rate is a high-variance signal, as a locally good decision may be followed by teammate mistakes" — [arXiv 2607.10814](https://arxiv.org/abs/2607.10814).
- Foaster Werewolf benchmark (non-peer-reviewed): 6-player (2 wolves), 7 LLMs, 10 matches per pair round-robin, role-conditioned Elo (GPT-5 ≈1508 wolf / 1476 villager; GPT-OSS-120B 931 wolf) — [werewolf.foaster.ai](https://werewolf.foaster.ai/) (unverified beyond the page summary).
- InfiniteBM Werewolf aggregator shows how small-n Elo misleads: "GPT-5.4 (high) leads with 2241.79 Elo across 7 games with 100% win rate" — [benchmarklist.com](https://benchmarklist.com/benchmarks/infinitebm_werewolf/) (aggregator; unverified).
- Frozen reference pools: Game Arena evaluates against a fixed 10-model pool; ParliamentBench against a frozen Llama 3.3 70B opponent; AvalonBench against rule-based bots (1,000-game baseline); Sarkar trains against frozen imposters then iterates self-play ("exploitability curves") — [Game Arena](https://arxiv.org/abs/2609.31473), [ParliamentBench](https://arxiv.org/abs/2607.28146), [AvalonBench](https://arxiv.org/abs/2310.05036), [Sarkar](https://arxiv.org/abs/2502.06060).

### Inferences
- Reported SEs are consistent with binomial noise: at p≈0.5, n=100 gives SE 0.05 (Xu 2024), n=30 gives ≈0.09 (MaKTO human, Strategist); detecting a 5 pp improvement at 95% confidence therefore needs on the order of 1,500–2,000 games per arm, and ParliamentBench's "14 pp at n=100" is exactly this arithmetic.
- No social-deduction paper computes Elo against a *frozen* reference pool across generations of a learning population; the closest templates are Game Arena's fixed 10-model pool + GTE and Sarkar's frozen-imposter exploitability curves.

### Gaps
- The GTE/polarix formulation (Appendix A.7 of Game Arena; Liu et al. ICLR 2025) was not read in full; its sample-complexity (games needed for a given CI) is not stated in the extracted text.
- The Kaggle "technical deep dive" blog post on Werewolf scoring was referenced but not located as a fetchable URL.

## Key Question 3 — Cost per game (tokens, dollars, minutes) with frontier APIs and with 7–8B local models

### Takeaway
Reported figures cluster at ~$0.25–1 and ~12–36 minutes per 7–9-player Werewolf/Mafia/Among Us game with mid-tier API models (gpt-4o-mini, DeepSeek, Llama-70B via OpenRouter), ~$0.01 for an unprobed DeepSeek Mafia game, ~62K completion tokens per 5-player Secret Hitler game, and ~17K tokens per 6-player Secret Mafia game; for an 8B local model, WOLF's 21 A100-GPU-hours per 100 games (12–13 min/game) is the only hard number found, and no paper reports tokens per game for an 8B Werewolf agent.

### Cited Findings
- Among Us: "we run 2054 games, which cost $2000 of OpenRouter API credits" (7 players, 18 models → ≈$0.97/game); "we run 400 games on Llama-3.3 and Phi-4, costing $100 in total" (≈$0.25/game); LLM-judge pass of 400 games with GPT-4o-mini cost "$2 in total"; probe training used "2 80GB A100 GPUs … for 100 hours at $2 an hour each" — [Among Us sandbox](https://arxiv.org/abs/2504.04072).
- MafiaScope (7-player Mafia): "At July 2026 prices a probed gpt-4o-mini game costs a median $0.36 and 36 minutes; a probed DeepSeek game about $0.26, an unprobed one $0.01" — [MafiaScope](https://arxiv.org/abs/2607.10645).
- WOLF (8-player Werewolf, one A100 40GB workstation): "approximately 12–13 minutes [per game] when using LLM calls, and less than 30 seconds with the deterministic mock analyzer"; 100 games ≈ 21 GPU-hours and 6 GB of NDJSON logs — [WOLF](https://arxiv.org/abs/2512.09187).
- ParliamentBench (5-player): "Gameplay resulted in 100 million total completion tokens" over >1,600 games (≈62K completion tokens/game; prompt tokens not reported); human sessions "lasted a total of six hours" — [ParliamentBench](https://arxiv.org/abs/2607.28146).
- MindGames Secret Mafia (6-player): 6,214 games, 34,359 player trajectories, 104.8M tokens (Qwen3-4B tokenizer), mean 5.3 turns/game → ≈16.9K tokens/game — [MindGames](https://arxiv.org/abs/2605.29512).
- WereWolf-Plus: all experiments (10 games per configuration; 12-player and 8-player; GPT-4o-mini at $1.10/$4.40 per M tokens, DeepSeek, Doubao) "total cost … 179.74 yuan" — [arXiv 2506.12841](https://arxiv.org/abs/2506.12841).
- Game Arena reports "average inference cost per game" for Werewolf in its cost–performance Pareto plot (Grok 4.1 Fast Reasoning cheapest, Gemini 3 Flash best value, Gemini 3 Pro max performance), and the Kaggle leaderboard has an "Average Inference Cost per Game" column; numeric per-game dollar values were not in the extracted text — [Game Arena](https://arxiv.org/abs/2609.31473), [Google blog](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/kaggle-game-arena-updates/).
- Training compute: Sarkar — one A40 (48 GB), <48 h for a 1.5B RWKV population; Stackelberg Speaker — 4 A800 × ~50 h for a 7B LoRA refiner; LSPO collected 1,000 self-play games to build the latent space (Llama-3-8B) — [Sarkar](https://arxiv.org/abs/2502.06060), [Stackelberg](https://arxiv.org/abs/2510.09087), [LSPO](https://arxiv.org/abs/2502.04686).
- MultiMind: MCTS planning 7.8 s per decision at 500 iterations (5-player ONUW) — [MultiMind](https://arxiv.org/abs/2504.18039).
- Anecdotal single-transcript test (not a game run): 138 API calls over a 36,281-character Werewolf transcript across 12 models cost "under $5", with median latency from 0.6 s (local Qwen 3.6-35B, thinking off) to 84.9 s (GPT-5-mini, effort high) — a 140× spread driven by thinking budgets — [dev.to post](https://dev.to/tommy_leonhardsen_81d1f4e/twelve-llms-played-werewolf-the-real-wolf-was-the-thinking-knob-2128).

### Inferences
- Scaling: 1,000 Werewolf games/generation at ~$0.3–1 (API) is $300–1,000/generation; at 12–36 min/game serially it is 200–600 machine-hours, so throughput for "thousands of generations" must come from parallel game instances and/or small local models.
- A 6-player Secret Mafia game at ~17K tokens is roughly 4× cheaper in tokens than a 5-player Secret Hitler game (~62K completion tokens), reflecting Secret Hitler's longer round structure (LLMs average 10.2 rounds).

### Gaps
- No paper found reports tokens-per-game or wall-clock for a 7–8B *local* model playing standard 7–9-player Werewolf; a search snippet attributed "3.5 minutes per game on a single A800 with Llama-3.1-8B-Instruct" and "70,000–80,000 tokens per 5-player ONUW game" to papers in the result list, but neither string could be located in the downloaded texts of MultiMind, ONUW, Stackelberg Speaker, WereWolf-Plus or LSPO — treat both as unverified.
- Game Arena's per-game Werewolf cost values (figure only) were not extracted.

## Key Question 4 — Populations, generations, cultural evolution, strategy-as-text transmission

### Takeaway
Population-style training exists on Werewolf (Xu ICML 2024 population of 6 LLM styles + checkpoints; Thinker's fictitious self-play over the last 500 checkpoints with population size 4; Sarkar's iterated self-play on Among Us; Strategist's round-robin among the top-10 text strategies on Avalon). Explicit strategy-as-text transmission exists in SPaRTan (self-play → written "playbook" prepended to the system prompt, transferred across games and distilled into 6 weaker students) and Strategist, but *generational cultural evolution with selection* has only been run on economic games (Donor Game: 12 agents × 10 generations; group-selection paper: 50–100 generations with Qwen3-30B), not on any social deduction game.

### Cited Findings
- Xu ICML 2024: "population composition: 6 initial pure LLM agents (3 Werewolf styles: quiet follower, active contributor, aggressive accusor; 3 Villager styles)", RL checkpoints "added progressively during training"; each episode "four players to be the learning agents … three players to be the fixed agents sampled from population" — [arXiv 2310.18940](https://arxiv.org/abs/2310.18940).
- Thinker: PPO with "fictitious self-play … remaining 6 players use models randomly selected from the most recent 500 checkpoints", "Population-based training with size of 4" — [arXiv 2402.02330](https://arxiv.org/abs/2402.02330).
- Sarkar (Among Us): "multiple iterations of self-play"; crewmate "win rate converges to between 0.51 and 0.56"; degenerate conventions emerged when all crewmates co-trained ("would lead to nearly perfect win rates during the first iteration of self-play"), fixed by freezing one crewmate — [arXiv 2502.06060](https://arxiv.org/abs/2502.06060).
- Strategist: strategies are natural-language guides refined via "LLM-guided revisions based on self-play feedback"; "population based self-play, where we conduct round-robin games among the top ten strategies"; outperforms Line/Greedy/BFS search "when controlling for the number of output tokens" — [arXiv 2408.10635](https://arxiv.org/abs/2408.10635).
- SPaRTan (Social Gym): "Play. The model M plays N self-play games … Reflect … write a first-person strategic playbook covering deception, detection, persuasion … Transfer. The reflection is prepended to an agent's system prompt"; N=30 games per round; alt (deceptive-side) win rate 24% → 36/36/43/35% under R1–R4 (peak R3), main side 76% → 66/59/67/63%; "the bulk of the gain arrives at R1 … additional rounds redistribute rather than accumulate"; setups include "strong-to-weak distillation into 6 student models on Resistance" — [Social Gym](https://arxiv.org/abs/2608.09128).
- WereWolf-Plus: cross-game "experience pool" ablation (retrieval of past experience) changes influence metrics — [arXiv 2506.12841](https://arxiv.org/abs/2506.12841).
- Donor Game cultural evolution (Vallinder & Hughes, Google DeepMind): "12 agents are initialized via a strategy prompt … 12 rounds … 6 new agents are initialized … the strategy prompt includes the strategies of surviving agents … repeated for 10 generations"; Claude 3.5 Sonnet > Gemini 1.5 Flash > GPT-4o — [arXiv 2412.10270](https://arxiv.org/abs/2412.10270).
- Group selection in LLM populations (Rahwan lab, Jun 2026): agents "transmit their natural-language prompts across generations under either individual- or group-level selection"; "Under group selection, prompts from high-performing groups are transmitted"; donor game with "benefit-cost ratio a = 1.5, group size g = 4", 50 generations (100 in a switching experiment), Qwen3-30B-A3B plus Llama 3 70B and GPT 5.5; "GPT-5.4 preemptively and gradually" adapts when told the selection rule — [arXiv 2606.23343](https://arxiv.org/abs/2606.23343).
- Adjacent (not social deduction): PopuLoRA, "population-based asymmetric self-play framework for RLVR post-training with teachers and students as specialized LoRA adapters on a shared frozen base" — [arXiv 2605.16727](https://arxiv.org/abs/2605.16727) (abstract only).
- MindGames competition behaviour: top agents' "winning strategies occupy" distinct regions; one team "lifts Villager win rate from 16% to 60% while Mafia remains at 88–96%" via iterative development — [MindGames](https://arxiv.org/abs/2605.29512).

### Inferences
- The SPaRTan playbook pipeline is essentially the startup's "transmissible strategy as text" primitive, already shown to transfer across Werewolves/Spyfall/Resistance and to distil into weaker models; nobody has yet combined it with generational selection, group competition, migration or verification-before-adoption on a deduction game.
- Sarkar's degenerate-convention finding is a concrete warning that co-trained populations on a deduction game can converge to brittle secret handshakes; a frozen-reference pool (or a frozen teammate) is the published fix.

### Gaps
- No paper was found running cultural evolution / generational selection / swarms on Werewolf, Avalon, Among Us, Secret Hitler, Spyfall or Chameleon; the only evidence is on Donor-Game-style economic games.
- No paper credits "teachers" for students' improvement or verifies taught strategies before adoption in any of these games.

## Key Question 5 — Documented failure modes of these games as benchmarks

### Takeaway
The literature documents five recurring problems: (1) role-assignment luck and structural asymmetry (villagers 1.2% without talk; evil wins 83% in LLM-only Avalon; standard 8-player Werewolf is Seer-Doctor-exploitable at 73% villager win); (2) high outcome variance (14 pp undetectable at n=100); (3) opponent/table dependence and non-transitivity (win-rate τ = −0.33 across opponent swaps; per-game Elo inversions); (4) format/invalid-action noise that dominates leaderboards (50.3% error games in Secret Mafia; thinking-budget latency 140×); (5) degenerate self-play conventions and pretraining familiarity.

### Cited Findings
- Role asymmetry: "Without [communication], Villagers win a mere 1.2% of 100,000 simulated games" — [Werewolf Arena](https://arxiv.org/abs/2407.13943); "E VIL wins 83.3% of the games" in the all-GPT-3.5 Avalon arena — [AvalonBench](https://arxiv.org/abs/2310.05036); ReCon baseline 15%/85% good/evil — [ReCon](https://arxiv.org/abs/2310.01320); "the standard 8-player Werewolf configuration is heavily skewed toward the Villager team … the Seer publicly reveals their identity immediately, and the Doctor protects them consecutively every night" (73.4% villager win) — [Game Arena](https://arxiv.org/abs/2609.31473); Social Gym: "no model plays both sides at the same level, and the gap usually favors the minority/deceptive role … For the strongest models this reverses under matched-capability self-play" — [Social Gym](https://arxiv.org/abs/2608.09128); Among Us: Phi-4 better as crewmate, Llama-3.3 better as impostor (400 games) — [Among Us](https://arxiv.org/abs/2504.04072).
- Variance: "cannot reliably resolve overall win-rate differences below roughly 14 percentage points" at n=100 — [ParliamentBench](https://arxiv.org/abs/2607.28146); "final win rate is a high-variance signal" — [Auditing](https://arxiv.org/abs/2607.10814); "10 for each model pair, may not provide statistically robust results" — [Werewolf Arena](https://arxiv.org/abs/2407.13943); win rate is "a macroscopic metric" that misses role-specific competence — [ParliamentBench](https://arxiv.org/abs/2607.28146), [Beyond Survival](https://arxiv.org/abs/2510.11389).
- Opponent dependence / non-transitivity: "Because every model in Table 1 is measured against a single opponent, we ran an anchor–opponent tournament … win rate … −0.33" Kendall τ across opponent classes — [ParliamentBench](https://arxiv.org/abs/2607.28146); per-game Elo "inversions" where the smallest model "places near the top on others" — [Social Gym](https://arxiv.org/abs/2608.09128); GTE chosen because it "allows for non-transitive performance cycles, which are common in social and strategic games but not captured by Elo-style systems" — [Kaggle search summary](https://www.kaggle.com/benchmarks/kaggle/werewolf) (unverified wording), consistent with [Game Arena](https://arxiv.org/abs/2609.31473).
- Format / invalid-action noise: Secret Mafia track "Confounded (Error 50.3%)" — "the overall results were skewed by a small subset of models that generated an unusually high number of errors"; "invalid actions and forfeits can distort leaderboard meaning"; TrueSkill "compress[es] into a narrow band" and can be inflated "when opponents fail" — [MindGames](https://arxiv.org/abs/2605.29512); Spyfall forfeits invalid moves ("an invalid move by the spy results in a victory for the non-spies") — [Spyfall](https://arxiv.org/abs/2601.09017); smaller models' "error rate is significantly higher" in Unity Werewolf — [FDG'25](https://dl.acm.org/doi/10.1145/3723498.3723702); "reasoning spend is a property of the configuration" with vendors' thinking knobs behaving inconsistently — [dev.to](https://dev.to/tommy_leonhardsen_81d1f4e/twelve-llms-played-werewolf-the-real-wolf-was-the-thinking-knob-2128).
- Degenerate self-play / exploitability: crewmates "come up with simple strategies that result in high win rates but are easy to overcome with a more intelligent imposter" — [Sarkar](https://arxiv.org/abs/2502.06060); Seer-Doctor exploit under standard rules — [Game Arena](https://arxiv.org/abs/2609.31473).
- Contamination / sandbagging: "it is likely that models know about Among Us from pre-training and are aware of the rules"; "A potential failure mode is sandbagging" — [Among Us](https://arxiv.org/abs/2504.04072).
- LLM-judge cost and subjectivity: evaluations that "fall back on LLM judges, which are costly" vs rule-decided outcomes — [Social Gym](https://arxiv.org/abs/2608.09128); utterance-level judgments "are inherently subjective" — [Beyond Survival](https://arxiv.org/abs/2510.11389).
- Safety-tuning interference: GPT-4 "refuses to craft deceptive content" when asked directly but produces it in Avalon context — [ReCon](https://arxiv.org/abs/2310.01320); uncensored variants change role win rates (e.g. gpt-oss-120B Hitler-role win 95%→40%) — [ParliamentBench](https://arxiv.org/abs/2607.28146).
- Objective drift: self-preservation objectives cut Village win rate "by 13.75% on average across all model–role" pairs — [Even More Deception](https://arxiv.org/abs/2607.26120).

### Inferences
- Any population metric must be role-balanced and seat-balanced (Social Gym does this by construction; Game Arena by GTE); otherwise group differences of a few points are swamped by who drew Werewolf.
- Invalid-action handling must be fixed and logged separately from skill (MindGames' Secret Mafia track lost its signal to this).

### Gaps
- No paper quantifies prompt-wording sensitivity of win rates for a fixed model on these games (only format/thinking-budget effects were found).

## Key Question 6 — Visual / replay tools

### Takeaway
Replay tooling exists but is mostly text-log viewers: Werewolf Arena's web viewer (archived), MafiaScope's interactive D3 viewer with belief probes and fork-and-replay, Game Arena/Kaggle trajectory snapshots with a streaming replay panel, Secret Hitler's reload-from-JSON replay, and a Unity 3D Werewolf; Among Us has Jupyter-based analysis plus released logs, and Sarkar's embodied Among Us is a 2D grid that is inherently drawable.

### Cited Findings
- Werewolf Arena: "interactive web-based viewer for exploring gamelogs" (`npm run start`); repo archived read-only Sept 24 2025 — [GitHub](https://github.com/google/werewolf_arena).
- MafiaScope: "An interactive visualizer" built from append-only JSONL, "viewer (D3 SPA) + fork API server", "Fork-and-replay" of any state with counterfactual re-rolls (480 registered forks); live demo at karpovilia.github.io; corpus of "162 probed seven-player games (109,999 parsed probe answers)" — [MafiaScope](https://arxiv.org/abs/2607.10645).
- Game Arena: logs "an immutable snapshot of the complete game state, including the model's action" per turn; a panel "supports both a streaming mode—simulating token-by-token generation"; harness released with "full game trajectories" — [Game Arena](https://arxiv.org/abs/2609.31473), [repo](https://github.com/google-deepmind/game_arena).
- Secret Hitler framework: games stored as JSON; "Games can be reloaded from these files, enabling replay from any chosen state with alternative agents or strategies"; anonymous web interface for human play — [Bauer 2026](https://arxiv.org/abs/2605.22826), [ParliamentBench](https://arxiv.org/abs/2607.28146).
- Unity Werewolf (FDG '25): "simulation and evaluation tool developed using the Unity game engine" with a memory stream per agent — [ACM DL](https://dl.acm.org/doi/10.1145/3723498.3723702).
- Among Us sandbox: Jupyter notebooks (e.g. `reports/2025_02_26_deception_ELO_v3_ci.ipynb`), HF-hosted 400 full-game logs and 810 summaries; no dedicated replay UI mentioned — [repo 7vik/AmongUs](https://github.com/7vik/AmongUs); AmongAgents has a text "gameplay interface" screenshot (Figure 9) and a human-player mode — [AmongAgents](https://arxiv.org/abs/2407.16521).
- TextArena: "UI for humans to play against the models, supporting any games added" and a TrueSkill leaderboard with 283 models evaluated — [TextArena](https://arxiv.org/abs/2504.11442).
- Foaster: "Full game replays for 4 games across 5 different models are available on GitHub" — [werewolf.foaster.ai](https://werewolf.foaster.ai/) (unverified).
- Hoodwinked is playable against GPT-3.5 at hoodwinked.ai — [arXiv 2308.01404](https://arxiv.org/abs/2308.01404).

### Inferences
- For "a human watches a replay and sees why one population is better", MafiaScope's belief-probe timeline is the closest existing instrument (it shows what each agent believed after every utterance, not just who won); Werewolf/Mafia therefore has the best interpretability tooling, Among Us the best *visual* potential (grid world), the others only transcripts.

### Gaps
- The Kaggle Werewolf game viewer's features could not be verified (page is JS-rendered); the ACM Unity paper's full text returned HTTP 403, so its replay features are known only from the abstract.
- A WebFetch summary of ParliamentBench claimed a "game replay system", but no such term appears in the PDF text; treat as unverified (the JSON reload feature is from the companion Bauer 2026 paper).
