# Negotiation and Strategy Board Games as LLM-Population Sandboxes (Diplomacy, Catan, Civilization, others) — as of 2026-10-05

Scope: assessment of each candidate game against the five sandbox criteria (API/simulator; long-run cost; existing LLM/MARL literature with baselines; rigorous metric; interpretability/visible group competition). Everything below is sourced inline; items I could not verify are in the Gaps subsections and marked as such.

## Key Question 1 — Diplomacy (CICERO, Welfare Diplomacy, 2025 AI Diplomacy tournaments, 2026 follow-ups, engine/API, cost, evaluation, non-transitivity, visualizer)

### Takeaway
Diplomacy has by far the richest LLM/MARL literature of any candidate (CICERO 2022, Diplodocus 2023, Welfare Diplomacy 2023, Richelieu 2024, DipLLM 2025, AI Diplomacy 2025, several 2026 papers) and a mature open-source engine with a visualizer, but full-press (natural-language) games are extremely expensive for population-scale runs: >$100 and 1–36 hours per game with frontier models, >3M tokens per game in Welfare Diplomacy, and published LLM studies use 5–20 games per condition. Evaluation is also structurally noisy (7-player, alliance-dependent, population-dependent), which is why the strongest published results use either no-press variants with fixed bot populations and ~1,000 games, or hundreds of games against humans with score-share/Elo.

### Cited Findings

**Engine / API**
- The `diplomacy/diplomacy` package is "an open-source DATC-compliant Diplomacy game engine, a client-server architecture for network play, a web interface to play against bots and to visualize games, and a DAIDE-compatible adapter"; programmatic play uses a `Game()` object with `get_all_possible_orders()`, `set_orders()`, `process()`; alternate maps via `Game(map_name='pure')`; the README states compatibility with "Python 3.5, 3.6, and 3.7"; licensed AGPLv3; 184 stars / 52 forks at fetch time — [diplomacy/diplomacy GitHub](https://github.com/diplomacy/diplomacy)
- Games can be exported and visualized through the web interface via "Load a game from disk"; the `diplomacy/research` repo holds supervised and RL models for no-press Diplomacy; a DAIDE server relays (does not parse) press — [GitHub search summary of diplomacy org](https://github.com/diplomacy), [diplomacy/research README](https://github.com/diplomacy/research/blob/master/README.md)
- The Good Start Labs `AI_Diplomacy` repo "extends the original Diplomacy project with LLM-powered agents" and is "built on the Python diplomacy package"; games run via `lm_game.py`; `experiment_runner.py` launches `--iterations` games with `--parallel` process pooling; supports OpenAI (GPT-4o, GPT-4.1, o3, o4-mini), Anthropic (Sonnet, Opus), Google (Gemini 2.0 Flash, 2.5 Pro), OpenRouter (Llama, Qwen, DeepSeek), DeepSeek and Together clients; global and per-model token limits via `--max_tokens` / `--max_tokens_per_model`; games configured with `--max_year` (examples 1905–1910); includes an `ai_animation/` Node/React "3D map with unit movements and battles", "phase-by-phase playback controls", and a chat window of diplomatic messages; copyright "Good Start Labs 2025" — [GoodStartLabs/AI_Diplomacy](https://github.com/GoodStartLabs/AI_Diplomacy)
- `diplobench` (sam-paech) uses the `python-diplomacy` package (boardgamers fork) for adjudication; 7 powers, test model always plays Austria, other six powers are gemini-2.0-flash-001; games run "up to 50 game-years" with a "4-round negotiation phase before each movement turn"; outputs turn-by-turn SVG maps (`gamestate_renders/`) and animated WebP; author's own caveat: "Not really economical to use as a benchmark since each round takes a lot of API calls" and results are "single games, so may not be representative" — [sam-paech/diplobench](https://github.com/sam-paech/diplobench)
- CICERO code and checkpoints are public; the repo "is configured to run in a high-GPU cluster environment" and training commands target Slurm, though "one can run them locally on an individual 8-GPU-or-more GPU machine, but training may be very slow" — [facebookresearch/diplomacy_cicero](https://github.com/facebookresearch/diplomacy_cicero)

**CICERO (Science 2022) and no-press RL baselines**
- From August to October 2022 CICERO played 40 games against 82 anonymous humans in a webDiplomacy.net league; it "achieved more than 2x the average score of its opponents and ranked in the top 10% of participants who played more than one game" (average score 25.8% vs 12.4% for the 82 humans); it placed 1st in an 8-game tournament with 21 participants; it sent an average of 130 messages per game — [Meta AI: Diplomacy and CICERO](https://ai.meta.com/research/cicero/diplomacy/); [Science DOI 10.1126/science.ade9097](https://www.science.org/doi/10.1126/science.ade9097); [InfoQ summary](https://www.infoq.com/news/2022/12/meta-diplomacy-cicero/)
- Diplodocus (no-press, ICLR 2023): in a 200-game no-press tournament with 62 human participants, two Diplodocus agents "achieved a higher average score than all other participants who played more than two games, and ranked first and third according to an Elo ratings model"; in a fixed-population bot setting Diplodocus-Low/High scored 29% and 28% vs 20% for the next-best agent (DNVI-NPU retrained) — [Mastering No-Press Diplomacy via Human-Regularized RL (arXiv 2210.05492)](https://arxiv.org/pdf/2210.05492)
- The BRPI line (NeurIPS 2020) frames evaluation as 1-vs-6 win rates against a fixed population, interpreted as whether a population "can be 'invaded' by a different agent, from an evolutionary game theory perspective" — [Learning to Play No-Press Diplomacy with Best Response Policy Iteration](https://arxiv.org/pdf/2006.04635)
- Evidence of population dependence (non-transitivity): the Diplodocus paper reports that an agent trained purely by self-play "plays worse against a population of human-imitation agents" than human-regularized agents do — [arXiv 2210.05492](https://arxiv.org/pdf/2210.05492)

**Welfare Diplomacy (2023)**
- General-sum variant: each year players receive "Welfare Points (WPs) equal to the difference between the number of SCs they control and their number of units on the board"; games "last ten years" in the primary experiments; "no winner" — objective is to maximize own WPs; implemented "in an open-source Diplomacy library"; code at mukobi/welfare-diplomacy — [arXiv 2310.08901 HTML](https://arxiv.org/html/2310.08901); [repo](https://github.com/mukobi/welfare-diplomacy)
- Models: GPT-4-0613, GPT-3.5-turbo-16k-0613, GPT-4-base, Claude-2.0, Claude-instant-1.2, Llama-2-70B-Chat; "five runs with different random seeds per experimental group"; experiments "summed to more than three million tokens for most games"; authors note that even without fine-tuning "our experiments were still computationally expensive" which "limited us to only five games per experimental condition"; baseline agents "attain high social welfare but are exploitable" — [arXiv 2310.08901 HTML](https://arxiv.org/html/2310.08901); [abstract](https://arxiv.org/abs/2310.08901)

**LLM agents 2024–2025 (Richelieu, DipLLM, Democratizing Diplomacy, DSGBench)**
- Richelieu (NeurIPS 2024): self-evolving LLM agent with memory ("game state, sub-goals, negotiation messages, and actions"), reflection, and self-play; tested with GPT-4, ERNIE Bot, Spark Desk, Llama 3; "typically, 1000 rounds are played to obtain the average results"; in press games vs CICERO: win rate 6.83% vs 6.03%, Most-SC rate 8.63% vs 6.90%, C-Diplo score "about 10% higher"; no compute/cost figures — [arXiv 2407.06813 HTML](https://arxiv.org/html/2407.06813v1); [NeurIPS 2024 PDF](https://proceedings.neurips.cc/paper_files/paper/2024/file/df2d62b96a4003203450cf89cd338bb7-Paper-Conference.pdf)
- DipLLM (ICML 2025): LoRA fine-tune of a Llama 3 8B backbone with an autoregressive unit-level action factorization; claims to surpass CICERO using "only 1.5% of the data required by the state-of-the-art Cicero model" — [arXiv 2506.09655](https://arxiv.org/abs/2506.09655); [ICML 2025 listing](https://mlanthology.org/icml/2025/xu2025icml-dipllm/)
- "Democratizing Diplomacy" (Aug 2025): a harness letting "any out-of-the-box local LLMs play full-press Diplomacy without fine-tuning"; a 24B model "can reliably complete matches"; introduces "Critical State Analysis"; code "will be open sourced" — [arXiv 2508.07485](https://arxiv.org/abs/2508.07485)
- DSGBench (Mar 2025) includes Diplomacy, Civilization (CivRealm), and Stratego among six games; "10 matches per scenario against either built-in AIs or GPT-4o-mini"; Diplomacy social-reasoning score GPT-4o 83.27 vs GPT-3.5 Turbo 74.25; no cost figures — [arXiv 2503.06047 HTML](https://arxiv.org/html/2503.06047v2); [DSGBench repo](https://github.com/DeciBrain-Group/DSGBench)

**2025 AI Diplomacy tournaments (Every / Good Start Labs) and 2026 follow-ups**
- "Over 15 runs of AI Diplomacy, which ranged from one to 36 hours in duration," o3 won by "maintaining false alliances for dozens of turns before executing perfectly-timed betrayals" while Claude 4 Opus "refused to betray anyone—even when losing" — [Every: We Made Top AI Models Compete in a Game of Diplomacy](https://every.to/diplomacy) (page returned 404 when fetched 2026-10-05; numbers from the search snippet); corroborated by [Latent Space: Good Start Labs](https://www.latent.space/p/good-start-labs) ("o3 won all the games by planning a future betrayal", "Claude Opus 4 refused to lie and got destroyed")
- Cost/duration: per-game cost "over $100 without any retries"; DeepSeek-R1-05-28 "took nearly three days per game" while being "around 200 times cheaper than o3"; Gemini 2.5 Flash "finished entire games in minutes"; launch stream had "50,000 live viewers"; 3D interface in Three.js; combining reasoning with final actions "reduces hallucinations dramatically" — [Every: How We Made AI Diplomacy Work](https://every.to/p/how-we-made-ai-diplomacy-work)
- Good Start Labs' public leaderboard: "Each model play 20 games of AI Diplomacy against a weak opponent (Mistral: Devstral Small 1.1)"; "Overall Performance" "combines how many supply centers the model captures with an additional bonus for speed of capture"; additional views "Betrayal Tendency" and "Steerability"; page dated 2026-10-05 (model table did not render in the fetch) — [goodstartlabs.com/leaderboards/diplomacy](https://goodstartlabs.com/leaderboards/diplomacy)
- September 2026 rankings reported: "Grok 4 Fast is the least likely to betray you in Diplomacy" and "don't trust Gemini 2.5 Pro"; Good Start Labs claims "fine-tuning a model on the strategy game Diplomacy improved its performance on customer support and industrial operations benchmarks"; a "Battle of the Bots" with $1,000 prize for prompting an agent to victory (o3 leading; Claude 4 Sonnet with 1M context "very competitive") — [Latent Space: Good Start Labs](https://www.latent.space/p/good-start-labs); [rl-list vendor profile](https://www.rl-list.com/vendors/good-start-labs)
- 2026 research use of the harness: "Data-Centric Interpretability for LLM-based Multi-Agent RL" (Feb 2026) runs "large-scale reinforcement learning training runs" of LLM agents on Full-Press Diplomacy, applies SAEs plus LLM summarizers, and reports "+14.2%" score improvement from system-prompt augmentation — [arXiv 2602.05183](https://arxiv.org/abs/2602.05183)

### Inferences
- For a population study needing thousands of games, full-press Diplomacy with frontier models is infeasible on cost alone (≥$100/game × thousands = $100k+, plus multi-hour wall-clock per game). No-press Diplomacy with the `diplomacy` engine and scripted/RL bots (DipNet, Diplodocus checkpoints) is cheap and has 1,000-game evaluation precedent (Richelieu), but drops the negotiation that makes Diplomacy interesting.
- Published LLM-Diplomacy evaluations are statistically thin (5 games/condition in Welfare Diplomacy, 15 runs in AI Diplomacy, 20 games/model on the Good Start leaderboard, single games in diplobench). The leaderboard's choice of a fixed weak opponent and a supply-center-plus-speed score is itself evidence that raw 7-way LLM-vs-LLM win rate is too noisy for ranking.
- Transmissible strategies in Diplomacy are naturally textual (system prompts, negotiation playbooks — the "Battle of the Bots" prompt competition is exactly that), not code; verifying a taught strategy requires expensive full games.
- Group competition is visible in-game (alliances, SC counts on the map) and the Three.js/web visualizers plus message logs make "why did they win" interpretable, which is the strongest point for Diplomacy on criterion 5.

### Gaps
- Could not fetch the main Every article (404) to confirm exact per-model win counts across the 15 runs; numbers are from search snippets and the Latent Space profile.
- No source gives tokens-per-game for AI Diplomacy; only ">$100/game" and the Welfare Diplomacy ">3M tokens" figure.
- Exact Elo/score tables of the Good Start Labs leaderboard were not retrievable (dynamic page).
- CICERO's per-game inference compute (GPU count during live play) was not found in accessible sources; unverified.
- Whether the `diplomacy` package's stated Python 3.5–3.7 compatibility is a hard constraint today is unverified; the AI_Diplomacy repo builds on it, so it evidently runs on modern Python in practice.

## Key Question 2 — Settlers of Catan (Catanatron, LLM-Catan papers 2024–2026, trading, visualizer, use of win rate vs reference bots)

### Takeaway
Catan via Catanatron is the cheapest, most measurable candidate: a pip-installable Python simulator claiming thousands of games per minute, a Gymnasium env, a CLI for batch bot-vs-bot play with a React web UI for replay, built-in Random/WeightedRandom/VictoryPoint/ValueFunction/GreedyPlayouts/MCTS/AlphaBeta bots with published head-to-head win rates, structured player-to-player trade actions in the engine, and a 2025 LLM paper (Agents of Change / HexMachina) that evolves strategies as Python code and evaluates with 10×100-game runs to ±3% CIs. The 4-player dice game is high-variance (AlphaBeta itself only hits ~51% in the paper's matchup), so thousands of games per evaluation are required, which Catanatron can afford.

### Cited Findings

**Simulator / API**
- "Catanatron is a high-performance simulator and strong AI player for Settlers of Catan. You can run thousands of games in the order of seconds. The goal is to find the strongest Settlers of Catan bot possible." — [bcollazo/catanatron README](https://github.com/bcollazo/catanatron)
- Docs headline: "Run thousands of Catan games per minute between different bots"; "Train reinforcement learning agents using an OpenAI Gym-compatible environment"; sections on "Simulation Hooks" and "Graphical User Interface" — [docs.catanatron.com](https://docs.catanatron.com/)
- CLI `catanatron-play --players=R,R,R,W --num=100` with `--output`/`--output-format` (JSON datasets); Gymnasium env `gymnasium.make("catanatron/Catanatron-v0")`; PyPI package `catanatron` with extras `[web,gym,dev]`; Docker web UI at `http://localhost:3000` to "watch, inspect, and play games"; GPL-3.0; 444 stars / 146 forks; 977 commits — [README](https://github.com/bcollazo/catanatron); [PyPI](https://pypi.org/project/catanatron/)
- Repo last pushed 2026-09-16 (GitHub API, fetched 2026-10-05) — [GitHub API](https://api.github.com/repos/bcollazo/catanatron)
- Engine constants read from source: `TURNS_LIMIT = 1000` and `vps_to_win: int = 10` default in `Game.__init__` — [catanatron/game.py](https://github.com/bcollazo/catanatron/blob/master/catanatron/catanatron/game.py)
- Player-to-player trading is implemented at the engine level as structured actions: `ActionType` includes `MARITIME_TRADE`, `OFFER_TRADE`, `ACCEPT_TRADE`, `REJECT_TRADE`, `CONFIRM_TRADE` ("11-tuple. first 10 as in OFFER_TRADE, last is color of accepting player"), `CANCEL_TRADE`; an `ActionPrompt.DECIDE_TRADE` phase exists — [catanatron/models/enums.py](https://github.com/bcollazo/catanatron/blob/master/catanatron/catanatron/models/enums.py); `game.py` validates offers with `is_valid_trade` ("does not give away resources or trade matching resources") and accepts an `OFFER_TRADE` "if its your turn and you have already rolled" even when not in `playable_actions` — [catanatron/game.py](https://github.com/bcollazo/catanatron/blob/master/catanatron/catanatron/game.py), [catanatron/models/player.py](https://github.com/bcollazo/catanatron/blob/master/catanatron/catanatron/models/player.py)

**Built-in bots and reference win rates**
- Documented players: AlphaBeta(n=2), ValueFunction, GreedyPlayouts(n=25), MCTS(n=100), WeightedRandom, VictoryPoint, Random; "AlphaBeta(n=2)" won "80% vs ValueFunction" in 25 games; "ValueFunction" won "90% vs GreedyPlayouts(n=25)" in 25 games; "the best bot right now is Alpha Beta Search with a hand-crafted value function"; recommended path is to subclass `AlphaBetaPlayer` with better value-function weights — [docs: Making Catanatron Stronger](https://docs.catanatron.com/advanced/making-catanatron-stronger)
- Author's results log: random playout to completion "takes around 0.3 secs"; early MCTS (25 playouts per action) beat Randoms 5–0 but averaged 301.6 turns and ~1024 s per game; DQN/CEM attempts "not better than random"; a learned value function won 63% vs Randoms with games "around 30s" — [docs/RESULTS_LOG.md](https://github.com/bcollazo/catanatron/blob/master/docs/RESULTS_LOG.md)
- Third-party note on search cost: alpha-beta at depth 3 ~2.5x faster after optimization (3.0 s → 1.2 s over 6 sampled decisions); MCTS with 100 simulations ~3 s per turn in Python — [yangml103/catanatron PR #1](https://github.com/yangml103/catanatron/pull/1) (secondary fork; unverified against upstream)

**LLM-Catan papers (2025–2026)**
- "Agents of Change: Self-Evolving LLM Agents for Strategic Planning" (arXiv June 2025, revised Oct 2025; renamed HexMachina in v2) benchmarks LLM agents on Catanatron "from a simple game-playing agent to systems capable of autonomously rewriting their own prompts and their player agent's code"; evolved players "achieve a 54% win rate, matching or slightly exceeding the strongest human-crafted AlphaBeta baseline" — [arXiv 2506.04651 abstract](https://arxiv.org/abs/2506.04651); [project page](https://nbelle1.github.io/agents-of-change/)
- HexMachina v2 details: roles Orchestrator, Coder, Analyst, Researcher, Strategist (streamlined config without Strategist/Researcher was best); Coder = GPT-4 Mini, Claude 3.7 as orchestrator backend, Mistral Large for support roles; Table 2 win rates: HexMachina-GPT "54.1% [51%, 57%]" (8.2±0.1 VP), HexMachina-Mistral 49.2% (7.8±0.2), HexMachina-Claude 38.4% (7.2±0.2), LLM Player (Reflexion, Claude) "16.4% [3%, 30%]" (5.2±1.2), AlphaBeta "51.0% [48%, 54%]" (7.8±0.2), Random "0.2%"; main comparison run "10 times with 100 games per run"; learning curves "10 steps, each evaluating FooPlayer across 30 games"; LLM Player baseline limited to "20 games" due to inference cost; opponent AlphaBeta with "depth-2 search (default), a 20 s decision cap"; data "collected over 60 hours across two machines (MacBook Pro 2019, 16GB; MacBook M1 Max 2021, 32GB)"; evolved strategies "stored as executable Python classes inheriting from a Player interface"; limitations: coarse metrics, LLM "occasionally hallucinated code or heuristics", "expensive to run due to inference costs, restricting the number of trials", performance "closely tied to the quality of the underlying model" — [arXiv 2506.04651v2 HTML](https://arxiv.org/html/2506.04651v2)
- The same work was submitted to ICLR 2026 as "HexMachina: Self-Evolving Multi-Agent System for Continual Learning of Catan" and was withdrawn — [OpenReview V0Fb4pwhS4](https://openreview.net/forum?id=V0Fb4pwhS4)
- The paper notes prompt-centric agents (ReAct, Reflexion) "must re-interpret large, evolving game states each turn, quickly saturating context windows and losing strategic consistency" — [arXiv 2506.04651](https://arxiv.org/abs/2506.04651)

**Other Catan simulators**
- TAG (Tabletop Games Framework, Java) includes Catan among "more than 20 modern tabletop games" with MCTS/RHEA/OSLA agents; PyTAG is the Python API — [TAG design paper arXiv 2009.12065](https://arxiv.org/pdf/2009.12065); [PyTAG arXiv 2405.18123](https://arxiv.org/html/2405.18123v1)

### Inferences
- Catanatron satisfies criterion 1 (pip install, CLI batch runs, Gym env, Player interface) and criterion 2 (sub-second games with scripted bots; LLM calls are the only expensive part). A "population" design where LLMs write/teach Python `Player` strategies and the simulator evaluates them in thousands of games against frozen AlphaBeta/ValueFunction bots maps directly onto HexMachina's published protocol.
- Variance is the main cost: HexMachina needed 1,000 games to get ±3% CIs, and AlphaBeta's own 51% shows the strongest scripted bot is only modestly above the pack in the paper's matchup. Budget ≥500–1,000 games per evaluated strategy.
- Trading is structured (resource tuples), not natural-language, so "negotiation" in Catanatron is a bargaining protocol rather than free-form diplomacy; cheap bots can reject all offers, so trade-based group competition must be designed deliberately.
- Catan's "group competition" is weak (free-for-all, 4 players); visibility of why one population wins comes from the web UI replay and from the code diff of evolved strategies, which is strong on interpretability.

### Gaps
- No authoritative games-per-second table for each bot type; only the README/docs claims ("thousands of games in the order of seconds / per minute") and the old results log (0.3 s per random game). Unverified for AlphaBeta-vs-AlphaBeta games.
- HexMachina Table 2 lists both HexMachina (54.1%) and AlphaBeta (51.0%) above 50%; the exact seat composition of each 100-game matchup was not extracted, so compare only within the paper's protocol.
- Whether the default CLI/Gym bots ever issue `OFFER_TRADE` (i.e., whether domestic trading is exercised by default) was not verified from source.
- Could not fetch the author's Medium post ("5 Ways NOT to Build a Catan AI", 403) for per-approach win rates beyond the results log.
- No 2024–2026 paper found that benchmarks LLMs on Catan negotiation/trading specifically; the only LLM-Catan paper found is Agents of Change/HexMachina.

## Key Question 3 — Civilization (CivRealm/Freeciv, 2026 follow-ups, LLM results, cost, long-horizon issues)

### Takeaway
CivRealm (ICLR 2024) is a serious open-source Freeciv environment with Gymnasium and LLM interfaces, diplomacy/chat actions, and 10 mini-game types × 10,000 instances, but full games are very long (several hours to days), state/action spaces explode (10^15→10^650 states), both RL and LLM agents "struggle to make substantial progress in the full game," and 2026 LLM work still reports ~367k tokens per 150-turn episode (SAGA) or $31–229 and 2–8 hours per run (CivBench on Civ VI) with n=10–23 runs. It fails the thousands-of-games criterion for LLM populations.

### Cited Findings
- CivRealm "empowers each agent to act as a player in the open-source turn-based strategy game Freeciv"; "an imperfect-information general-sum game with a changing number of players"; provides interfaces for "tensor-based agents that focus on learning, and language-based agents that emphasize reasoning"; "the state can grow from 10^15 to 10^650, and the action space can expand from 10^4 to 10^166"; full games "from several hours to several days"; score aggregates "population, researched technologies, wonders, units built and killed, culture, and if spaceship is achieved"; supports "Communication between players through diplomatic actions and natural language chat" (trading technologies, ceasefires, alliances) — [arXiv 2401.10568 HTML](https://arxiv.org/html/2401.10568v1); [ICLR 2024 proceedings](https://proceedings.iclr.cc/paper_files/paper/2024/hash/76d2f8e328e1081c22a77ca0fa330ca5-Abstract-Conference.html)
- Benchmarks: "10 types of mini-games" with "10,000 instances for each type" (4 development, 6 battle, 1 diplomacy; easy/normal/hard); RL reached "~90%" on some development mini-games; RL on full game trained "over 2 million steps" learned "primarily focusing on unit production"; LLM baselines BaseLang vs Mastaba compared "on 10 maps with distinct geography. Each method plays 5 full games on each map"; overall "both RL- and LLM-based agents struggle to make substantial progress in the full game" — [arXiv 2401.10568 HTML](https://arxiv.org/html/2401.10568v1)
- Repo: Docker Freeciv-web server, Python ≥3.8, Gymnasium API, multiplayer mode with separate client ports; `civrealm-llm-baseline` package; GPL-3.0; 162 stars; 1,248 commits on dev — [bigai-ai/civrealm](https://github.com/bigai-ai/civrealm)
- DSGBench's Civilization track uses CivRealm, "10 matches per scenario," ~141 average iterations per game; Gemini 1.5 Flash scored 72.88 strategic planning vs GPT-3.5 Turbo 32.94 — [arXiv 2503.06047 HTML](https://arxiv.org/html/2503.06047v2)
- SAGA (June 2026, CivRealm): backbone Doubao-Seed-1.8 (GPT-4o-mini for generalization); episodes capped at 150 turns on a fixed 23×23 map seed vs "2 built-in AI civilizations plus active barbarians"; n=10 games per method; Score SAGA 60.7±14.0 vs CoS 47.8±20.3, HIMA 43.7±22.3, Mastaba 39.0±14.2; token use per game SAGA 367k±56k (258k in / 109k out), CoS 281k±51k, HIMA 387k±103k; cross-game evolution over five successive episodes reaches Game-5 score 90; ablations: removing on-demand tools −49%, SceneGraph −25%, inner loop −26%; limitation: "Barbarian/pirate spawning remains fully random; fixed map seed does not eliminate variance" — [arXiv 2606.29932 HTML](https://arxiv.org/html/2606.29932v1)
- CivBench (Sept 2026, Civilization VI via MCP with 76 tools): "A single episode spans 300+ turns" with "5–15 tool calls" per turn; 23 admissible runs across Claude Opus 4.6 (8), GPT-5.4 (7), Gemini 3.1 Pro (6), Kimi-K2.5 (1); outcomes 3 victories / 20 defeats; "within-model variance comparable to between-model differences"; "Each full-game run costs approximately $31–229 in API fees and takes 2–8 hours"; "Only 21% of pre-harness runs completed"; requires commercial Civ VI — [arXiv 2609.02459 HTML](https://arxiv.org/html/2609.02459v1)

### Inferences
- Even the cheapest 2026 CivRealm setup (150 turns, ~370k tokens, small Chinese backbone) is ~100x the per-game token cost of a Catanatron LLM-written-bot evaluation (where the LLM is not called per turn), and sample sizes of 10 runs with ±14–22 score SDs make population comparisons underpowered.
- Civilization offers the most visible group competition (civilizations, alliances, wars) and rich diplomacy, but the long-horizon and tooling burden (Docker Freeciv-web, 76-tool MCP for Civ VI) dominate. Mini-games are cheap but are single-agent tasks, not population competition.

### Gaps
- No steps-per-second or seconds-per-turn figure for CivRealm was found in the paper or README.
- Mastaba/BaseLang per-game token or dollar cost not reported in CivRealm; only SAGA's 2026 token table is available.
- CivRealm repo last-commit date not retrievable from the fetch.

## Key Question 4 — Other games with multi-agent/LLM literature (Stratego, Scrabble, Monopoly, Risk, Splendor, Terraforming Mars, Dominion) and multi-game frameworks

### Takeaway
Stratego has the strongest MARL result (DeepNash; Ataraxos in Nature Sept 2026 at "a few thousand dollars" of self-play) but is a 2-player hidden-information game with no negotiation. Monopoly got an LLM benchmark in May 2026 (FinBoardBench, 108 matches), Scrabble has a live LLM Elo arena (blog, 2026), and Splendor/Terraforming Mars/Dominion have search/RL baselines inside TAG/PyTAG/RainbowArena but no LLM-population literature; Risk has only blog-level LLM work. Multi-game frameworks (TAG/PyTAG, RainbowArena, OpenSpiel-based Game Reasoning Arena, DSGBench) give cheap simulators and reference bots but thin LLM baselines.

### Cited Findings
- Stratego: DeepNash (model-free MARL) — [arXiv 2206.15378](https://arxiv.org/pdf/2206.15378); Ataraxos (Nature, 30 Sept 2026) beat Pim Niemeijer 15–1–4 in a 20-game series, trained "on 16 H100 GPUs over one week, running roughly 160 million self-play games at a cost the authors describe as 'a few thousand dollars'", vs DeepNash's reported ~5.5 billion games at $3–4.5M; uses self-play RL plus decision-time planning and a generative model of hidden pieces — [aiweekly summary of the Nature paper](https://aiweekly.co/alerts/ataraxos-tops-world-stratego-player-15-1-4-in-nature-paper); [arXiv 2511.07312](https://arxiv.org/pdf/2511.07312). PyTAG PPO self-play in Stratego reached win rates 0.91/0.95/0.88 vs Random/OSLA/MCTS — [PyTAG arXiv 2405.18123](https://arxiv.org/html/2405.18123v1). DSGBench Stratego averages ~1270 iterations per game, the longest in the suite — [arXiv 2503.06047](https://arxiv.org/html/2503.06047v2)
- Scrabble: ScrabbLLM is "a live arena where language models play Scrabble against each other, with real Scrabble rules, ELO ratings, and game replays," pitting GPT-5, Claude Opus, Gemma and others — [abhiraghunathan.com, 2026-03-06](https://www.abhiraghunathan.com/blog/2026/03/06/scrabbllm) (blog, not peer-reviewed)
- Monopoly: FinBoardBench (May 2026) evaluates 9 LLMs (GPT-5.4, Gemini-3.1-Pro Preview, GLM-5.1, HY3 Preview, DeepSeek V4 Pro, Doubao-2.0-Pro, Kimi K2.6, Qwen-3.6-Plus, Mimo V2.5 Pro) on Cashflow, Acquire and Monopoly in 4-player matches against three fixed LLM opponents; "108 game matches, comprising 4,282 rounds and 15,602 active player turns"; Monopoly win rate reported 13.88%; no repo or cost figures — [arXiv 2605.27896](https://arxiv.org/html/2605.27896). Non-LLM: hybrid model-free deep RL Monopoly agent that imitates a rule-based agent and can trade — [arXiv 2103.00683](https://arxiv.org/pdf/2103.00683); ISI GNOME Monopoly multi-agent domain — [Springer chapter](https://link.springer.com/chapter/10.1007/978-3-031-33054-4_7); open Python simulator — [giogix2/MonopolySimulator](https://github.com/giogix2/MonopolySimulator)
- Risk: only blog-level LLM work found ("Exploring the Strategic Capabilities of LLMs in a Risk Game Setting", agents get dynamically generated prompts with rules, board state and attack vectors) — [Medium](https://medium.com/data-science/exploring-the-strategic-capabilities-of-llms-in-a-risk-game-setting-43c868d83c3b) (403 on fetch; snippet only); classical work: hybrid Monte Carlo Risk agent — [SBGames](https://sol.sbc.org.br/index.php/sbgames_estendido/article/download/23664/23493/); 2005 multi-agent Risk system with auction negotiation — [DiVA](https://www.diva-portal.org/smash/get/diva2:831093/FULLTEXT01.pdf)
- Splendor: Rinascimento framework for statistical forward planning agents ("highly-stochastic partially-observable multi-player game") — [arXiv 1904.01883](https://arxiv.org/pdf/1904.01883); RainbowArena (AAMAS 2025 / KBS 2025) is a toolkit "for reinforcement learning and large language models in competitive tabletop games" with six games including Splendor and Ticket to Ride, a self-play RL framework and "a standardized prompt structure for LLM agents" — [AAMAS 2025 PDF](https://www.ifaamas.org/Proceedings/aamas2025/pdfs/p2639.pdf); [enochliu98/RainbowArena](https://github.com/enochliu98/RainbowArena); DDQN "super-human" Splendor agent (MSc thesis) — [DiVA](https://www.diva-portal.org/smash/get/diva2:1779339/FULLTEXT01.pdf)
- Terraforming Mars: TAG implementation (AIIDE-21) with MCTS (rollout depth 10, UCT K=2, 1000 forward-model calls) and OSLA agents using a points-if-game-ended heuristic; "Each test configuration was run 100 times" for 1–5 players; MCTS best — [TAG: Terraforming Mars PDF](https://cdn.aaai.org/ojs/18902/18902-52-22668-1-2-20211004.pdf); full open-source TM implementation (Node/TypeScript, used by the online community) — [terraforming-mars/terraforming-mars](https://github.com/terraforming-mars/terraforming-mars)
- Dominion: deep RL agent playing multiple strategies (AIIDE 2023) — [AAAI AIIDE](https://ojs.aaai.org/index.php/AIIDE/article/view/27518); genetic-algorithm Dominion AI (CS229) — [Stanford](https://cs229.stanford.edu/proj2016/report/Mok-Creating%20a%20Dominion%20AI%20using%20Genetic%20Algorithms-report.pdf); no LLM-Dominion paper found.
- Multi-game frameworks: TAG has "more than 20 modern tabletop games" (Catan, Pandemic, Terraforming Mars, Dominion...) with MCTS/RHEA/OSLA; MCTS had the highest win rate in 5 of 6 competitive games (45.5% overall) — [TAG arXiv 2009.12065](https://arxiv.org/pdf/2009.12065), [PyTAG](https://arxiv.org/html/2405.18123v1). Game Reasoning Arena (OpenSpiel-based; Tic-Tac-Toe, Connect Four, Kuhn Poker, matrix games; LLM vs random/human/LLM/self-play; Ray-parallel; no numeric win rates in paper) — [arXiv 2508.03368](https://arxiv.org/html/2508.03368v3), [repo](https://github.com/SLAMPAI/game_reasoning_arena). DSGBench (StarCraft II, Civilization, Street Fighter III, Diplomacy, Werewolf, Stratego; 10 matches/scenario) — [arXiv 2503.06047](https://arxiv.org/html/2503.06047v2). Cattle Trade: single long-horizon game "lasting 50–60 turns" combining auctions, hidden offers, bargaining, bluffing — [arXiv 2605.14537](https://arxiv.org/pdf/2605.14537). lmgame GamingAgent (ICLR 2026) — [repo](https://github.com/lmgame-org/GamingAgent)

### Inferences
- None of the "other" games combines (a) negotiation, (b) a fast open simulator with strong reference bots, and (c) an LLM literature with published numbers. Stratego has (b) and superb MARL baselines but no negotiation and is 2-player; Monopoly now has (c) at small scale (108 matches) but no strong open reference bots; Splendor/TM/Dominion have (b) via TAG/RainbowArena but only search/RL baselines.
- If the startup wants a cheap non-negotiation control game, TAG/PyTAG (Java forward model, MCTS/RHEA bots, PPO baselines) or Stratego would do; for negotiation the realistic choices remain Diplomacy (expensive, rich) vs Catan (cheap, structured trading).

### Gaps
- No arXiv paper on LLM agents in Risk was found; only a Medium post (not fetched) and pre-LLM agents.
- No LLM paper on Terraforming Mars, Dominion, or Splendor was found (RainbowArena supports LLM agents but I could not extract numeric LLM results from the abstract).
- FinBoardBench per-model Monopoly win-rate table, cost, and repo were not extracted.
- Ataraxos numbers are from a secondary news summary of the Nature paper; the primary arXiv/Nature text was not fetched.

## Key Question 5 — Transmissible strategies (code vs written heuristics), evaluation cost for thousands of games, and sample sizes used

### Takeaway
Only Catan/Catanatron has a published protocol where an LLM-written strategy is a self-contained, testable artifact (a Python `Player` subclass) evaluated by a fast simulator in 1,000 games; Diplomacy and Civilization strategies in the literature are prompts, memories or playbooks whose verification costs a full LLM-played game (>3M tokens, >$100, hours). Published sample sizes range from 5 games/condition (Welfare Diplomacy) to 1,000 rounds (Richelieu) and 10×100 games (HexMachina).

### Cited Findings
- Catan: HexMachina's evolved strategies are "stored as executable Python classes inheriting from a Player interface, with methods for action evaluation and game-phase-aware heuristics," with an adapter layer for stable API access; evaluation "10 times with 100 games per run" yields CI half-widths of ~3 points (e.g., "54.1% [51%, 57%]"); whole study "collected over 60 hours across two machines" — [arXiv 2506.04651v2](https://arxiv.org/html/2506.04651v2). Catanatron's own recommendation for stronger bots is to subclass `AlphaBetaPlayer` and change value-function weights, i.e., strategy = weight vector + heuristic code — [docs](https://docs.catanatron.com/advanced/making-catanatron-stronger)
- Diplomacy: Richelieu's transmissible state is a memory of "game state, sub-goals, negotiation messages, and actions" plus reflection, improved via self-play; "1000 rounds are played to obtain the average results" — [arXiv 2407.06813](https://arxiv.org/html/2407.06813v1). Good Start Labs' Battle of the Bots is a prompt-writing competition ($1,000 prize) — [Latent Space](https://www.latent.space/p/good-start-labs). The 2026 interpretability paper improved score "+14.2%" by augmenting the system prompt with SAE-derived hypotheses, i.e., a written heuristic transmitted via prompt — [arXiv 2602.05183](https://arxiv.org/abs/2602.05183). Welfare Diplomacy: five games per condition, >3M tokens per game — [arXiv 2310.08901](https://arxiv.org/html/2310.08901). AI Diplomacy: 15 runs, 1–36 h each, >$100/game — [Every](https://every.to/p/how-we-made-ai-diplomacy-work). Leaderboard: 20 games per model vs a fixed weak opponent — [goodstartlabs.com](https://goodstartlabs.com/leaderboards/diplomacy)
- Civilization: SAGA's "cross-game evolution module" carries lessons across "five successive episodes" and is "architecture-agnostic, plug-and-play"; n=10 per method, ~367k tokens per 150-turn game — [arXiv 2606.29932](https://arxiv.org/html/2606.29932v1). CivRealm baseline: 10 maps × 5 full games — [arXiv 2401.10568](https://arxiv.org/html/2401.10568v1). CivBench: 23 runs, $31–229 and 2–8 h each — [arXiv 2609.02459](https://arxiv.org/html/2609.02459v1)
- Human/RL reference evaluations for calibration: CICERO 40 games vs 82 humans — [Meta AI](https://ai.meta.com/research/cicero/diplomacy/); Diplodocus 200-game human tournament (62 humans) and fixed-population bot scores — [arXiv 2210.05492](https://arxiv.org/pdf/2210.05492); TAG Terraforming Mars 100 runs per configuration — [AIIDE-21 PDF](https://cdn.aaai.org/ojs/18902/18902-52-22668-1-2-20211004.pdf); FinBoardBench 108 matches total across 3 games × 9 models — [arXiv 2605.27896](https://arxiv.org/html/2605.27896)

### Inferences
- "Thousands of games" is realistic only when the LLM is out of the per-turn loop: code/heuristic strategies run by a fast simulator (Catanatron, TAG, OpenSpiel, no-press Diplomacy with bots). Any design that needs the LLM to speak every phase (full-press Diplomacy, CivRealm LLM agents) tops out at tens of games per condition in the literature.
- A "verify before adopting" mechanic is cheapest in Catan: a student can run a taught `Player` for 200–1,000 games vs frozen AlphaBeta in minutes; in Diplomacy the same verification is a multi-hour, >$100 experiment per sample.
- Credit-for-students'-improvement requires low-noise before/after deltas; with Catan's ±3% CI at 1,000 games, only effects ≥5 points are reliably detectable per teaching event.

### Gaps
- No paper reports an explicit cost-per-game for Catanatron LLM-evolved bots beyond the "60 hours on two laptops" aggregate; token spend per evolution step not reported.
- No published work found that transmits strategies between LLM agents in any of these games (teaching/migration/population mechanics); all cited self-improvement is single-lineage (HexMachina, Richelieu, SAGA).

## Key Question 6 — Known problems: luck and 4-player variance, kingmaking/alliance noise, LLM cost, simulator availability

### Takeaway
Every candidate has a documented noise problem: Catan's dice/draws (strongest scripted bot ≈51% in a 4-seat matchup; 1,000 games for ±3%), Diplomacy's 7-player alliance dynamics (6–9% win rates for the best agents; population-dependent performance; betrayal as a measured dimension), and Civilization's stochastic barbarians and within-model variance "comparable to between-model differences." LLM cost ranges from ~$0 (LLM-written bots in Catanatron) to >$100/game (full-press Diplomacy) and $31–229/run (Civ VI).

### Cited Findings
- Catan variance: AlphaBeta "51.0% [48%, 54%]" vs HexMachina "54.1% [51%, 57%]" with 1,000 games each; Reflexion LLM player "16.4% [3%, 30%]" with only 20 games — [arXiv 2506.04651v2](https://arxiv.org/html/2506.04651v2). Reference bot gaps are large at the bottom (AlphaBeta 80% vs ValueFunction; ValueFunction 90% vs GreedyPlayouts) but measured on only 25 games — [docs](https://docs.catanatron.com/advanced/making-catanatron-stronger)
- Diplomacy alliance/kingmaking noise: best agents win only 6.83% (Richelieu) vs 6.03% (CICERO) of press games, so papers report Most-SC rate and C-Diplo scores in addition to wins — [arXiv 2407.06813](https://arxiv.org/html/2407.06813v1); Welfare Diplomacy baselines were "highly exploitable" by single defectors — [arXiv 2310.08901](https://arxiv.org/html/2310.08901); Good Start Labs tracks "Betrayal Tendency" and "Steerability" as separate leaderboard axes and benchmarks against a fixed weak opponent — [goodstartlabs.com](https://goodstartlabs.com/leaderboards/diplomacy); self-play agents "play worse against a population of human-imitation agents" (population dependence) — [arXiv 2210.05492](https://arxiv.org/pdf/2210.05492); 1v6 invasion framing — [arXiv 2006.04635](https://arxiv.org/pdf/2006.04635)
- Civilization variance: SAGA score SDs of ±14–22 on n=10 and random barbarian spawning even with fixed map seed — [arXiv 2606.29932](https://arxiv.org/html/2606.29932v1); CivBench "within-model variance comparable to between-model differences," only 21% of pre-harness runs completed — [arXiv 2609.02459](https://arxiv.org/html/2609.02459v1)
- LLM cost: >$100/game and 1–36 h (AI Diplomacy) — [Every](https://every.to/p/how-we-made-ai-diplomacy-work); >3M tokens/game (Welfare Diplomacy) — [arXiv 2310.08901](https://arxiv.org/html/2310.08901); ~367k tokens per 150-turn CivRealm game — [arXiv 2606.29932](https://arxiv.org/html/2606.29932v1); $31–229 and 2–8 h per Civ VI run — [arXiv 2609.02459](https://arxiv.org/html/2609.02459v1); HexMachina LLM-player baseline capped at 20 games "due to inference costs" — [arXiv 2506.04651v2](https://arxiv.org/html/2506.04651v2); diplobench author: "not really economical" — [diplobench](https://github.com/sam-paech/diplobench)
- Simulator availability: Catanatron pip/GPL-3.0, active (pushed 2026-09-16) — [GitHub API](https://api.github.com/repos/bcollazo/catanatron); `diplomacy` engine AGPLv3 with web visualizer and DAIDE — [GitHub](https://github.com/diplomacy/diplomacy); AI_Diplomacy repo with 3D animation — [GitHub](https://github.com/GoodStartLabs/AI_Diplomacy); CivRealm Docker Freeciv-web, GPL-3.0 — [GitHub](https://github.com/bigai-ai/civrealm); CivBench requires commercial Civilization VI — [arXiv 2609.02459](https://arxiv.org/html/2609.02459v1); TAG/PyTAG Java+Python with 20+ games — [arXiv 2405.18123](https://arxiv.org/html/2405.18123v1); RainbowArena — [GitHub](https://github.com/enochliu98/RainbowArena)

### Inferences
- For a population experiment the binding constraints are per-game cost and evaluation noise, which point to Catan/Catanatron (code strategies, frozen scripted opponents, 1,000-game evaluations) as the only candidate meeting criteria 1–4 at thousands-of-games scale today; Diplomacy wins on criteria 3 and 5 (literature depth, visible alliances, visualizers) but only at tens of games per condition unless restricted to no-press with bots.
- A hybrid is plausible: use Catanatron for the quantitative population loop and a small number of full-press Diplomacy or CivRealm games as qualitative/visual showcases, since both have replay/3D visualizers.

### Gaps
- No source quantifies kingmaking frequency in LLM Diplomacy games or in Catan bot games; the alliance-noise evidence above is indirect (low absolute win rates, exploitability, population dependence).
- No measured games-per-second for Catanatron with AlphaBeta on all four seats; the "thousands of games in seconds" claim is for fast bots (Random/Weighted) by implication, unverified.
