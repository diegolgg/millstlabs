# LLM populations / evolution / self-play on games, and game-agnostic self-improving baselines (as of 2026-10-05)

Scope note: this covers (A) prior work that put LLM populations, evolutionary loops or self-play on a specific game, (B) game-agnostic self-improving / evolutionary LLM systems that could be run on a new game as compute-matched baselines, (C) which of these already contain groups/islands, migration, teaching, ancestor credit, or verify-before-adopt, and (D) 2025–2026 cultural-evolution / social-learning work. Everything below is sourced inline; items I could not verify are flagged "UNVERIFIED" or listed under Gaps. "Code public" means a repo URL is stated in the paper/page I fetched.

## KQ1. Which games have published LLM-population / evolutionary / self-play results? (Table A)

### Takeaway
Only a handful of games have *trained or evolved* LLM-agent results with numbers: Werewolf (population RL + latent-space self-play), Avalon/GOPS (population self-play of text strategies), Catan (evolved compiled player), Kuhn Poker / TicTacToe / Simple Negotiation / Mini-Hanabi (self-play RL via TextArena: SPIRAL, MARSHAL), Hanabi (SFT/RL fine-tune), Little Alchemy 2 (collective innovation + evolved transmission programs), the Donor/IPD/CPR cooperation games (cultural evolution of strategy text), and Minecraft (skill library; 500–1000-agent social simulation but no learning loop). Pokémon, NetHack/BALROG, StarCraft II, chess, poker, Codenames, 20Q, Overcooked, Sokoban have strong *benchmark* or *single-agent* LLM results but no LLM-population numbers.

### Inferences
- The only games with *more than one* trained/evolved LLM-agent result and reported win rates against common opponents are Werewolf (Xu 2023 vs LSPO 2025, both report vs ReAct/ReCon) and Avalon (AvalonBench, Strategist, agent-society, with RL baselines DeepRole). Both lack reliable public training code.
- Kuhn Poker / TicTacToe / Simple Negotiation / Mini-Hanabi on TextArena is the only setting where two independent open-code self-play RL systems (SPIRAL, MARSHAL) report numbers with compute (8xH100, ~25 h) — but the games are too small to be the "skillful game" a population thesis needs.
- Catan is the only "skillful" board game with an evolved-code agent beating a hand-crafted baseline under a stated budget (20 Coder calls/phase, 60 h on two laptops); it is single-lineage, so a population method has a clean ablation target.
- Little Alchemy 2 and the Donor game have the richest *cultural-transmission* baselines, but they are discovery/cooperation tasks rather than competitive skill games.

### Gaps
- Richelieu (Diplomacy) win-rate numbers vs Cicero were not extracted from the fetched abstract; needs full-text read.
- Bachrach et al. IJCAI 2025 (PSRO with LLM code bots): PDF failed to parse; no population size / iteration count / results retrieved.
- Project Sid: no public code found; cultural-transmission numbers (meme counts, conversion rates) are described qualitatively in the fetched text.
- No LLM-population or evolutionary results found for Craftax, Lux AI, Jericho/TextWorld (beyond BALROG's TextWorld subset), Codenames, 20Q, Overcooked, Sokoban. A claim that "LLM agents are competitive with PPO and PBT on Overcooked but reach half the score on Hanabi" surfaced in search snippets but I could not attribute it to a primary source — UNVERIFIED.
- Werewolf Xu et al. code status: project site only.

## KQ2. Game-agnostic self-improving systems: interface, compute, code, runs on games (Table B)

### Takeaway
All the evolutionary-code harnesses (ShinkaEvolve, OpenEvolve, FunSearch, AlphaEvolve) need the same thing — an initial program with marked mutable blocks and an evaluate() returning scalar metrics (+ optional text feedback) — so any game whose policy can be expressed as code and scored by simulated matches is a drop-in. Agent-level self-improvers (DGM, HGM) need a benchmark harness and are expensive ($22k/2 weeks for DGM; HGM ~$5k for all three methods on SWE-60). Economy of Minds, PopuLoRA, Multi-Agent Evolve and AgentRxiv are the closest existing "organization-level" baselines; only EoM and Multi-Agent Evolve have public code today.

## KQ3. Which prior population works report learning curves vs compute, diversity, transfer, and seeds/replicates?

### Takeaway
Compute-vs-performance is reported only by HGM (CPU-hours, evaluation budget), ShinkaEvolve (samples), PopuLoRA (wall-clock on 8xH100), SPIRAL (steps x GPUs x hours), the harness study (3.1M rollouts with null distributions), and "From Solo to Social Learning" (matched token budgets). Replicate counts are mostly small or absent: HGM and PopuLoRA are single-run; Catan uses 10x100 games; Colas 2026 uses 5 searches x 30 sims; Sid uses 3–5 repeats for some experiments and 1 for the 500-agent run.

### Cited Findings
- HGM: budget of 800 evaluations (SWE-Verified-60) / 8000 (full); 2.38x / 6.86x fewer CPU-hours than DGM; results are single runs with no seed statement — [arXiv 2510.21614](https://arxiv.org/html/2510.21614v1)
- ShinkaEvolve: ~150 samples for circle packing; AIME over 75 generations with 3 independent runs per candidate; no cost disclosure — [arXiv 2509.19349](https://arxiv.org/html/2509.19349v1)
- PopuLoRA: 80 h vs 61 h on one 8xH100 node for 8x the adapters; "problem-space coverage keeps expanding throughout training" (diversity curve); single seed — [arXiv 2605.16727](https://arxiv.org/html/2605.16727)
- SPIRAL: 400 steps x 128 samples, 8xH100 ~25 h; transfer to 7 unseen games (44.9% avg vs Gemini-2.0-Flash-Lite) and to math (+8.7% avg); seed count not disclosed — [arXiv 2506.24119](https://arxiv.org/html/2506.24119v1)
- MARSHAL: transfer up to +28.7% on held-out games (Connect Four, Leduc, Simple Hanabi) — [arXiv 2510.15414](https://arxiv.org/html/2510.15414v3)
- Harness study: 12 model-problem pairs, >3.1M rollouts, 30 budget-matched variants, repeated-trial statistics with released null distributions; early performance predicts final outcome; adaptive allocation (start many harnesses, prune, reallocate) beats committing to one — [arXiv 2607.18235](https://arxiv.org/abs/2607.18235)
- "From Solo to Social Learning": explicit per-round token budget split between learning and acting; 8 environment seeds (bandit) and 6 population seeds (skill evolution); socially learning LLM populations were 30–52% *less* efficient than solo on a 25-arm bandit (10 agents, 100 rounds, 4,096 tokens/round), and IFBench gains at matched cost were +0.14±0.35 pp (GPT-OSS-120B) and +0.98±0.85 pp (GLM-5.3-Flash), not significant; an algorithmic hierarchical-UCB population *did* gain (+25.68 cumulative reward) — [arXiv 2609.38516](https://arxiv.org/html/2609.38516)
- Colas 2026: 5 independent evolutionary searches, 30 simulations per protocol configuration, performance reported at 150 and 300 steps — [arXiv 2608.24545](https://arxiv.org/html/2608.24545)
- Nisioti 2024: 10 trials per configuration; 200-step open-ended curves — [arXiv 2407.05377](https://arxiv.org/html/2407.05377)
- SwarmWorld: 4 matched world seeds per condition; held-out evaluation on 8 unseen disturbance schedules (transfer) — [arXiv 2608.26081](https://arxiv.org/html/2608.26081)
- Catan/HexMachina: 10 runs x 100 games with 95% CIs; 60 h on two laptops; deterministic experiments with fixed seeds used to isolate genuine improvements — [arXiv 2506.04651](https://arxiv.org/html/2506.04651)
- Project Sid: 3 sims (specialization), 4 per condition (taxation), 5 repeats (social perception), single 500-agent run — [arXiv 2411.00114](https://arxiv.org/html/2411.00114)
- Gupta et al. CPR game: 10 trials per condition (100 for rule-based validation) — [arXiv 2510.14401](https://arxiv.org/html/2510.14401)
- Cross-provider IPD: n=500 Moran iterations, code + Zenodo — [arXiv 2605.29874](https://arxiv.org/abs/2605.29874)
- Economy of Minds: SD reported (57.0±3.36 on MATH) but replicate count unspecified; no compute — [arXiv 2606.02859](https://arxiv.org/html/2606.02859v1)
- DGM: ~$22k / ~2 weeks per run (secondary summary) — [Gonzo ML](https://gonzoml.substack.com/p/darwin-godel-machine)

### Inferences
- A new population method that reports (i) performance vs LLM-call or token budget, (ii) ≥5 seeds, and (iii) released null distributions would exceed the reporting standard of every game-specific prior work above and match the harness study.
- The Jha/Kleiman-Weiner/Jaques negative result (social learning costs more than it returns for LLMs at matched budget) is the most direct published challenge to a "teaching improves populations" thesis and should be a named comparison.

### Gaps
- No prior game work reports learning curves vs *dollars* except DGM/HGM (coding, not games).
- Diversity metrics are reported only by PopuLoRA (coverage), SwarmWorld (behavioral differentiation 52.8% vs 31%), QDAIF (archive coverage); none on a competitive game.

## KQ4. 2025–2026 work on cultural evolution / cumulative culture / teaching / social learning between LLM agents

### Takeaway
Beyond the named references, the 2025–2026 literature adds: Colas et al. (evolved state-aware transmission programs, +33–37%), SwarmWorld (stigmergic technological descent with authorship chains, 50–200 agents), Jha–Kleiman-Weiner–Jaques (skill-file social learning is net-negative at matched token cost), Gupta/Rahwan (payoff-biased imitation + voted norms in a CPR game), Horibe (image-scoring norms in the donor game), Zúñiga Bolívar (cross-provider IPD Moran dynamics), Jones & Hauert (emergent culture with 3 agents and a decaying store), EvolveNet/CASCADE (shared harness/skill libraries), Braga-Neto labs (citation economy), Economy of Minds (market selection), and Moltbook analyses showing large agent "societies" with little genuine exchange.

### Games with the richest baseline set (explicit ranking)
1. **Werewolf** — two trained systems with win rates vs the same prompted baselines (ReAct, ReCon) and vs each other (LSPO 0.73/0.27 vs Xu 0.69/0.25), human games (600), plus Werewolf Arena and MultiMind — [arXiv 2502.04686](https://arxiv.org/html/2502.04686), [arXiv 2310.18940](https://arxiv.org/html/2310.18940v4), [arXiv 2407.13943](https://arxiv.org/html/2407.13943v1), [arXiv 2504.18039](https://arxiv.org/html/2504.18039v4). Weakness: no reliable public training code.
2. **Avalon** — AvalonBench (code), Strategist population self-play with RL (DeepRole) and human comparisons, agent-society paper — [arXiv 2310.05036](https://arxiv.org/pdf/2310.05036), [arXiv 2408.10635](https://arxiv.org/html/2408.10635), [arXiv 2310.14985](https://arxiv.org/html/2310.14985v3).
3. **TextArena small games (Kuhn Poker, TicTacToe, Simple Negotiation, Mini-Hanabi)** — SPIRAL and MARSHAL, both open code + checkpoints + compute — [arXiv 2506.24119](https://arxiv.org/html/2506.24119v1), [github thu-nics/MARSHAL](https://github.com/thu-nics/MARSHAL). Weakness: not "skillful" enough.
4. **Pokémon Showdown** — human Elo ladder anchor, PokéChamp (open), PokeLLMon, Metamon RL with 22M battles, NeurIPS 2025 challenge — [arXiv 2503.04094](https://arxiv.org/abs/2503.04094), [arXiv 2603.15563](https://arxiv.org/abs/2603.15563). Weakness: no LLM-population/evolution numbers yet; richest *absolute* anchor.
5. **Hanabi** — 17 LLMs benchmarked, RL self-play ceilings (>20–23), SFT/RL fine-tune datasets — [arXiv 2601.18077](https://arxiv.org/abs/2601.18077), [OpenReview](https://openreview.net/pdf?id=8apVsxtUqX).
6. **Catan (Catanatron)** — one evolved-code result with CIs, a built-in AlphaBeta anchor, a reproduction repo — [arXiv 2506.04651](https://arxiv.org/html/2506.04651).
7. **Little Alchemy 2** — richest *collective innovation / transmission* set (Nisioti 2024 with code; Colas 2026 with code and 15 baselines) — [arXiv 2407.05377](https://arxiv.org/html/2407.05377), [arXiv 2608.24545](https://arxiv.org/html/2608.24545). Not competitive.
8. **Donor / IPD / CPR cooperation games** — richest *cultural evolution of cooperation* set with code — [github aronvallinder/llm-donor-game](https://github.com/aronvallinder/llm-donor-game), [arXiv 2605.29874](https://arxiv.org/abs/2605.29874), [arXiv 2510.14401](https://arxiv.org/html/2510.14401). Not skill games.
9. **Minecraft** — Voyager (open) and Project Sid (closed) give qualitative anchors; no compute-matched population baselines — [arXiv 2305.16291](https://arxiv.org/abs/2305.16291), [arXiv 2411.00114](https://arxiv.org/html/2411.00114).
10. **NetHack/BALROG, StarCraft II, chess, poker** — standardized LLM leaderboards/benchmarks, zero LLM-population results — [balrogai.com](https://balrogai.com/), [arXiv 2508.10428](https://arxiv.org/abs/2508.10428).

### Inferences
- If the startup wants game-specific type-(A) baselines, Werewolf/Avalon (social deduction) or Catan (code-evolvable board game) are the only skillful games with published trained/evolved LLM-agent numbers; Pokémon Showdown gives the best absolute human anchor but would require the startup to establish the first LLM-population numbers itself.
- For type-(B) baselines, the cheapest credible set is ShinkaEvolve + OpenEvolve + GEPA + HGM + Economy of Minds at matched LLM-call budgets, with the harness study's protocol (repeated trials, null distributions, early-pruning adaptive allocation) as the evaluation standard.

### Gaps
- No system found that combines islands + migration + credited teaching + verification on any game; this is the thesis's open slot, but the negative social-learning result (Jha et al.) and SwarmWorld's best-artifact trade-off are the two closest published tests.
